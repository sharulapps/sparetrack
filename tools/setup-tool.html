Paste Firebase Config
Copy terus dari Firebase Console → Project Settings → SDK setup. Paste semua sekali — tool ini auto-extract nilai yang diperlukan.
2
Topic Notifikasi (ntfy)
Nama unik untuk notifikasi department/customer ini. Huruf kecil, tiada space. Contoh: customerabc_sparepart
2b
Topic Low Stock Alert (ntfy)
Topic ntfy untuk alert stok rendah. Kosongkan jika nak guna topic sama dengan step 2.
Hantar sekali sehari sahaja.
